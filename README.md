### Cómo Usar el Demo

1. **Abrir `index.html`** en navegador
2. **Landing Page**: Click "Empezar la Aventura"  
3. **Onboarding**: Completar chat con Sparky (5 pasos)
4. **Dashboard**: Explorar Bento Grid personalizado
5. **Calculadora**: Click 💰 para ver presupuesto detallado
6. **Explorar**: Navegar a segunda pestaña, buscar eventos
7. **Calendario**: Ver tercera pestaña, calendario interactivo
8. **Perfil**: Cuarta pestaña con logros y estadísticas
9. **Navegación**: Usar Ctrl+1-4 o swipe en móvil
10. **Crear Plan**: Desde cualquier evento, flujo completo
