# 🎯 Plan Saver - Guía de Navegación Completa

## 🚀 Sistema de Navegación Conectado

### **📍 Top Navbar (Aparece después del onboarding)**
- **🏠 Plan Saver Logo** → Regresa al Dashboard
- **🏠 Inicio** → Dashboard principal
- **🔍 Explorar** → Pantalla de eventos
- **📅 Calendario** → Vista de calendario
- **💰 Presupuesto** → Calculadora directa
- **📊 Stats** → Estadísticas rápidas
- **🔔 Notificaciones** → Centro de notificaciones
- **👤 Usuario** → Perfil personal

### **📱 Bottom Navigation (Siempre visible)**
- **🏠 Para Ti** → Dashboard
- **🔍 Explorar** → Eventos
- **📅 Mis Planes** → Calendario  
- **👤 Perfil** → Perfil completo

### **🍱 Dashboard - Todas las tarjetas son CLICKABLES:**
1. **Evento Principal** → Modal de creación de plan
2. **Actividad de Amigos** → Click → Explorar eventos
3. **Reto Semanal** → Click → Ver logros en Perfil
4. **Tu Calendario** → Click → Calendario completo
5. **Novedades Cerca** → Click → Explorar todos los eventos
6. **Tu Nivel** → Click → Ver perfil completo

### **🔗 Enlaces Cruzados en Cada Pantalla:**

**📍 Explorar:**
- ← Dashboard (botón superior)
- 📅 Mi Calendario (botón superior)
- 💰 Presupuesto (botón superior)
- Cada evento tiene botón "Crear Plan" y "💰"

**📍 Calendario:**
- ← Dashboard (botón superior)
- 🔍 Explorar Eventos (botón superior)
- 👤 Mi Perfil (botón superior)
- ➕ Nuevo Plan → Lleva a Explorar

**📍 Perfil:**
- 🏠 Dashboard (botón central)
- 🔍 Explorar (botón central)
- 📅 Calendario (botón central)
- 💰 Presupuesto (botón central)

### **⚡ Quick Actions (Botones flotantes)**
- **💰** → Calculadora de presupuesto
- **🔍** → Explorar eventos
- **📅** → Calendario

### **🗂️ Breadcrumb Navigation**
- Aparece en pantallas secundarias
- "🏠 Dashboard > 🔍 Explorar Eventos"
- Click en Dashboard para regresar

## 🎮 Atajos de Navegación

### **⌨️ Teclado:**
- **Ctrl+1** → Dashboard
- **Ctrl+2** → Explorar
- **Ctrl+3** → Calendario
- **Ctrl+4** → Perfil
- **Escape** → Cerrar modales

### **📱 Móvil:**
- **Swipe izquierda** → Siguiente pantalla
- **Swipe derecha** → Pantalla anterior
- **Tap en cualquier tarjeta** → Navegar

## 🔄 Flujos de Navegación Principales

### **🎵 Desde Dashboard a Evento:**
Dashboard → Click tarjeta evento → Modal plan → Presupuesto → Explorar más

### **🔍 Desde Búsqueda a Plan:**
Explorar → Buscar evento → Ver detalle → 💰 Presupuesto → Crear plan

### **📅 Desde Calendario a Acción:**
Calendario → Click día → Ver eventos → Explorar → Presupuesto

### **👤 Desde Perfil a Actividad:**
Perfil → Ver logros → Dashboard → Explorar eventos → Crear plan
